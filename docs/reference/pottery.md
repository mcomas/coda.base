# Chemical compositions of Romano-British pottery

The \`pottery\` data set contains the chemical composition of 45
specimens of Romano-British pottery. The measurements were obtained by
atomic absorption spectrophotometry and include nine oxides: Al2O3,
Fe2O3, MgO, CaO, Na2O, K2O, TiO2, MnO, and BaO.

The specimens come from five different kiln sites.

## Usage

``` r
pottery
```

## Format

An object of class `data.frame` with 45 rows and 11 columns.
