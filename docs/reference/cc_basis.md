# Canonical-correlation log-ratio basis

Construct an ilr basis rotated according to canonical correlations
between a compositional response data set and an explanatory data set.

## Usage

``` r
cc_basis(Y, X)
```

## Arguments

- Y:

  A compositional data set.

- X:

  An explanatory data set.

## Value

A matrix whose columns define a canonical-correlation-oriented ilr
basis.
