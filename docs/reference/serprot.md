# Serum proteins

The \`serprot\` data set records the percentages of four serum proteins
from blood samples of 30 patients. Fourteen patients have one disease
and sixteen have another.

The four-part compositions are formed by \\\[albumin,
pre\text{-}albumin, globulin\\ A, globulin\\ B\]\\.

## Usage

``` r
serprot
```

## Format

An object of class `data.frame` with 36 rows and 7 columns.
