# Hotel posts in social media

The \`weibo_hotels\` data set compares the use of Weibo (the Chinese
equivalent of Facebook) in hospitality e-marketing between small and
medium establishments and larger hotel businesses in China.

The 50 latest posts from the Weibo page of each hotel (\\n = 10\\) were
content-analysed and coded into a four-part composition: \\\[facilities,
food, events, promotions\]\\. Hotels were also classified by size as
large (\`L\`) or small (\`S\`).

## Usage

``` r
weibo_hotels
```

## Format

An object of class `data.frame` with 10 rows and 5 columns.
