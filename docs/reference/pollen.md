# Pollen composition in fossils

The \`pollen\` data set contains 30 fossil pollen samples from three
different locations (recorded in variable \`group\`). The measured
composition is the three-part composition \\\[pinus, abies, quercus\]\\.

## Usage

``` r
pollen
```

## Format

An object of class `data.frame` with 30 rows and 4 columns.
