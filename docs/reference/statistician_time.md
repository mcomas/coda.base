# A statistician's time budget

The \`statistician_time\` data set records the daily time budget of an
academic statistician across 20 working days. The six activities are
teaching (\`T\`), consultation (\`C\`), administration (\`A\`), research
(\`R\`), other wakeful activities (\`O\`), and sleep (\`S\`).

These activities may also be grouped into work (\`T\`, \`C\`, \`A\`,
\`R\`) and leisure (\`O\`, \`S\`). The data allow investigation of the
relationship between detailed time-allocation patterns and the broader
division between work and leisure.

## Usage

``` r
statistician_time
```

## Format

An object of class `data.frame` with 20 rows and 7 columns.
