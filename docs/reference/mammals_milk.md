# Mammals' milk

The \`mammals_milk\` data set contains the percentages of five
constituents of the milk of 24 mammals: \\\[W, P, F, L, A\]\\, where
\`W\` is water, \`P\` is protein, \`F\` is fat, \`L\` is lactose, and
\`A\` is ash.

## Usage

``` r
mammals_milk
```

## Format

An object of class `data.frame` with 24 rows and 6 columns.
