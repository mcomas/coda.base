# Milk composition study

In an attempt to improve the quality of cow milk, milk from thirty cows
was assessed before and after a controlled dietary and hormonal regime
over eight weeks. A control group of thirty cows kept under the usual
regime was also included.

The \`milk_cows\` data set provides the complete before/after milk
composition data for the sixty cows, with the proportions of protein
(\`pr\`), milk fat (\`mf\`), carbohydrate (\`ch\`), calcium (\`Ca\`),
sodium (\`Na\`), and potassium (\`K\`).

## Usage

``` r
milk_cows
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 116
rows and 10 columns.
